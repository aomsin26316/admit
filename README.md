## 📌 ภาพรวมของระบบ (Project Overview)

ระบบรับสมัครเรียนออนไลน์ (โควตา) วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ ประจำปีการศึกษา ๒๕๗๐ เป็นเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่ออำนวยความสะดวกในการรับสมัครนักเรียน นักศึกษาใหม่ ในระดับประกาศนียบัตรวิชาชีพ (ปวช.) และระดับประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) 
- **แบบฟอร์มใบสมัคร:** อ้างอิงตรงตามแบบฟอร์มใบสมัครฉบับกระดาษของสถานศึกษา 100%
- **Backend & Database:** ขับเคลื่อนด้วย **Google Apps Script (GAS)** ร่วมกับ **Google Sheets** ในฐานะฐานข้อมูล และ **Google Drive** สำหรับจัดเก็บไฟล์เอกสารแนบ
- **การแจ้งเตือน:** เชื่อมต่อระบบแจ้งเตือนผ่าน **LINE Notify** เมื่อมีผู้สมัครรายใหม่ และเมื่อเจ้าหน้าที่เปลี่ยนสถานะ
- **การจัดพิมพ์เอกสาร:** มีระบบ Auto-Generate เอกสารใบสมัครขนาด A4 แบบฟอร์มราชการ (ใช้ตัวเลขไทย) พร้อมพิมพ์หรือดาวน์โหลด PDF ได้ทันที
- **งานทะเบียน (Admin Portal):** รองรับการแยกสิทธิ์ (Admin / Registrar), ระบบบันทึกการมอบตัวพร้อมออกรหัสนักเรียนอัตโนมัติ, สถิติ Analytics ด้วย Chart.js และส่งออกข้อมูลตามแบบมาตรฐานงานทะเบียน สอศ. (แบบ ศธ.๐๒)

## 🗄️ โครงสร้างฐานข้อมูล (Google Sheets Database)

ระบบใช้ Google Sheets แบ่งออกเป็น 5 ชีตหลัก โดยมีฟังก์ชัน `initDatabase()` สร้างโครงสร้างตารางและหัวคอลัมน์ให้อัตโนมัติ:

1. **`Applicants`**: เก็บข้อมูลผู้สมัครครบทุกข้อ 1 - 6
   - เลขที่ใบสมัคร (`Q70-XXXX`), ปีการศึกษา, ระดับที่สมัคร, คำนำหน้า, ชื่อ, นามสกุล, เลขประจำตัวประชาชน 13 หลัก, วันเกิด, ข้อมูลบิดา, ข้อมูลมารดา, ที่อยู่ปัจจุบัน, ข้อมูลโรงเรียนเดิม, ผลการเรียนเฉลี่ยสะสม (GPAX 5 ภาคเรียน), สาขาวิชาที่เลือก, สถานะการสมัคร, รหัสนักเรียน, หมายเหตุ, วันที่ยื่นสมัคร
2. **`Documents`**: บันทึกข้อมูลและ URL ไฟล์แนบใน Google Drive
   - เลขที่ใบสมัคร, เลขบัตรประชาชน, ประเภทเอกสาร, ชื่อไฟล์, Google Drive File ID, URL สำหรับเปิดดูเอกสาร, วันที่อัปโหลด
3. **`StatusLog`**: บันทึกประวัติการเปลี่ยนสถานะ (Audit Trail)
   - วันเวลา, ผู้ดำเนินการ (Staff Username), เลขที่ใบสมัคร, การดำเนินการ/สถานะเดิมและใหม่, หมายเหตุ
4. **`Staff`**: ข้อมูลเจ้าหน้าที่และสิทธิ์การใช้งาน
   - Username, Password, ชื่อ-สกุล, ตำแหน่ง, สิทธิ์การใช้งาน (`ผู้ดูแลระบบ` / `เจ้าหน้าที่ทะเบียน`), สถานะ (`Active`)
5. **`Settings`**: การตั้งค่าระบบแบบ Dynamic
   - `IS_OPEN` (เปิด/ปิดรับสมัคร), `ACADEMIC_YEAR` (ปีการศึกษา 2570), `APPLY_START_DATE`, `APPLY_END_DATE`, `BRANCHES_PWC` (รายชื่อสาขา ปวช.), `BRANCHES_PWS` (รายชื่อสาขา ปวส.), `LINE_NOTIFY_TOKEN`

## 🚀 วิธีการติดตั้งและการ Deploy บน Google Apps Script

### ขั้นตอนที่ 1: สร้าง Google Sheets & Google Apps Script
1. ไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า **`ระบบรับสมัครออนไลน์_วท_ท่าหลวง_2570`**
2. ไปที่เมนู **ส่วนขยาย (Extensions)** &rarr; **Apps Script**
3. สร้างและคัดลอกไฟล์จากโฟลเดอร์ `backend/` ไปวางใน Apps Script:
   - ไฟล์ที่ 1: `Code.gs` (คัดลอกเนื้อหาจาก `backend/Code.gs`)
   - ไฟล์ที่ 2: `PdfGenerator.gs` (กดปุ่ม `+` &rarr; Script &rarr; ตั้งชื่อว่า `PdfGenerator`)
   - ไฟล์ที่ 3: `LineNotify.gs` (กดปุ่ม `+` &rarr; Script &rarr; ตั้งชื่อว่า `LineNotify`)
4. ในหน้าต่างโค้ด เลือกฟังก์ชัน **`initDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)** 1 ครั้ง
   - กดยินยอมสิทธิ์การเข้าถึงข้อมูล (Review Permissions) ของบัญชี Google
   - ระบบจะสร้างทั้ง 5 ชีต (`Applicants`, `Documents`, `StatusLog`, `Staff`, `Settings`) พร้อมข้อมูลเริ่มต้นให้ทันที

### ขั้นตอนที่ 2: การ Deploy เป็น Web App
1. ที่มุมขวาบนของ Apps Script กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** &rarr; **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกเลือกประเภทเป็น **เว็บแอป (Web app)**
3. ตั้งค่าการ Deploy ดังนี้:
   - **คำอธิบาย (Description):** `ระบบรับสมัครเรียนออนไลน์ โควตา 2570 v1.0`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me / อีเมลของคุณ)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ผู้สมัครภายนอกสามารถยื่นเอกสารได้)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

### ขั้นตอนที่ 3: เชื่อมต่อ Web App URL กับ Front-end
1. เปิดไฟล์ `js/app.js` แล้วนำ URL ที่ได้มาใส่ในตัวแปร:
   ```javascript
   const CONFIG = {
     GAS_API_URL: "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec",
     ...
   };
   ```
2. เปิดไฟล์ `js/admin.js` แล้วนำ URL มาใส่ในตัวแปร:
   ```javascript
   const ADMIN_CONFIG = {
     GAS_API_URL: "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec",
     ...
   };
   ```

## 🔔 การตั้งค่าการแจ้งเตือน LINE Notify

1. เข้าไปที่ [LINE Notify Service](https://notify-bot.line.me/) แล้วเข้าสู่ระบบด้วยบัญชี LINE
2. ไปที่ **หน้าของฉัน (My Page)** &rarr; เลื่อนลงมาที่ **ออก Token (Generate token)**
3. ตั้งชื่อการแจ้งเตือน เช่น `งานทะเบียน วท.ท่าหลวง` และเลือกกลุ่ม LINE ที่ต้องการให้ส่งแจ้งเตือน
4. คัดลอก Token ที่ได้ นำไปใส่ในชีต **`Settings`** ที่ช่อง `LINE_NOTIFY_TOKEN` หรือกรอกผ่านหน้าเมนูตั้งค่าใน **`admin.html`**

5. รอ 1 - 2 นาที เว็บไซต์จะออนไลน์พร้อมใช้งานทันทีที่:

## 📋 กฎการตรวจสอบข้อมูล (Validation Rules & PDPA)

1. **เลขประจำตัวประชาชน 13 หลัก:** ตรวจสอบความถูกต้องด้วยอัลกอริทึม Checksum Mod 11 ตามมาตรฐานกรมการปกครอง
2. **หมายเลขโทรศัพท์:** บังคับ 10 หลัก ขึ้นต้นด้วย 0 (เฉพาะตัวเลข)
3. **ผลการเรียนเฉลี่ยสะสม (GPAX):** ตรวจสอบค่าต้องอยู่ระหว่าง `0.00` ถึง `4.00`
4. **สาขาวิชา ปวช.:** สาขาวิชาอันดับ 1 และอันดับ 2 ต้องไม่ซ้ำกัน
5. **การป้องกันการสมัครซ้ำ:** ตรวจสอบเลขประจำตัวประชาชนในฐานข้อมูล ไม่สามารถสมัครซ้ำในปีการศึกษาเดียวกันได้
6. **การแนบไฟล์หลักฐาน:** รองรับไฟล์ JPG, PNG, PDF ขนาดไม่เกิน 5 MB ต่อไฟล์ มีระบบพรีวิวรูปถ่าย
7. **พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA):** มีกล่องข้อความชี้แจงวัตถุประสงค์และกล่อง Checkbox บังคับให้ผู้สมัครยินยอมก่อนบันทึกข้อมูล

## 🖨️ รูปแบบเอกสารราชการและการพิมพ์ (Official A4 Printing)

- เอกสารใบสมัครขนาดกระดาษ A4 มาตรฐาน
- แปลงตัวเลขอารบิกเป็น **ตัวเลขไทย (๐-๙)** ในส่วนหัวเอกสาร ปีการศึกษา และเลขที่ใบสมัคร
